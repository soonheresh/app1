# 환자 설문 관리 (PWA)

환자가 태블릿·휴대폰에서 설문지를 작성하고, 원장/직원이 같은 기기에서 응답을 확인·관리하는 설치형 웹앱(PWA)입니다.
빌드 과정이 없는 순수 HTML/CSS/JS이며, 오프라인에서도 동작합니다.

## 기능
- **환자 화면**: 설문지 선택 → 기본정보(이름·생년월일·성별·연락처) + 문항 작성 → 개인정보 수집 동의 → 제출. 제출 후 10초 뒤 첫 화면으로 자동 복귀(키오스크용).
- **관리자 화면** (PIN 잠금, 10분 무조작 시 자동 잠금)
  - 응답 목록: 이름·연락처 검색, 설문지·상태(신규/확인함/처리완료) 필터, CSV 내보내기(엑셀 한글 호환)
  - 응답 상세: 나이 자동 계산, 통증 척도 막대 표시, 상태 변경, 진료 메모, 인쇄
  - 설문지 편집: 문항 추가/복제/순서 변경/삭제, 8가지 문항 유형(단답·서술·숫자·날짜·단일선택·복수선택·예/아니오·0–10 척도), 필수 지정, 사용/중지
  - 설정: 기관명, PIN 변경, JSON 백업/복원, 응답 일괄 삭제
- 기본 설문지 2종(초진 문진표, 재진 경과 설문) 포함 — 자유롭게 수정 가능

## 실행
```bash
python3 -m http.server 8080   # 또는 아무 정적 웹서버
```
`http://localhost:8080` 접속. 실제 기기에 설치하려면 **HTTPS**로 배포해야 합니다(GitHub Pages, Netlify 등).
브라우저 메뉴의 "홈 화면에 추가 / 앱 설치"로 설치합니다.

초기 관리자 PIN은 `0000` 입니다. 처음 로그인 후 반드시 변경하세요.

## 데이터 / 개인정보
- 모든 데이터는 **해당 기기 브라우저의 IndexedDB에만** 저장되며 서버로 전송되지 않습니다.
- 기기 간 동기화는 되지 않습니다. 브라우저 데이터 삭제 시 사라지므로 설정 → 백업을 정기적으로 하세요.
- 백업 JSON/CSV 파일에는 민감한 건강정보가 들어 있으니 안전하게 보관하세요.
- PIN은 기기 내 간이 잠금이며, 의료기관 수준의 접근통제·암호화를 대체하지 않습니다.

## 파일 구조
```
index.html            앱 셸
styles.css            스타일 (다크모드·인쇄 대응)
manifest.webmanifest  PWA 매니페스트
sw.js                 서비스워커 (오프라인 캐시; 파일 수정 시 VERSION 올리기)
js/db.js              IndexedDB 래퍼
js/defaults.js        기본 설문지
js/app.js             라우팅·화면·로직
icons/                앱 아이콘
```
